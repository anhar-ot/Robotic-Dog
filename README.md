# Robotic Dog

## Overview

A mechanical design study of a quadruped ("robot dog") robot, modeled and assembled in Onshape.

## Tools used

- Onshape (CAD modeling and assembly)

## Components

- Body
- Body cover
- Left leg
- Right leg
- SG90 Micro Servo 9g (Tower Pro) x4
- M3 x 12mm socket button head cap screws

## Assembly algorithm

The robotic dog was assembled in the following order:

1. Build the body
2. Mount the servos
3. Attach the cover
4. Secure the screws
5. Attach the horns
6. Attach the legs
7. Check that all servos rotate freely
